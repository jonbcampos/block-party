# Ellie's Block Party

A falling-block game for Ellie, played on a phone held upright. Slide toy blocks into rows; full
rows flash and pop.

Two ways to play:

- **PLAY**: the classic game everyone knows.
- **BOOM!**: the Raccoon Bandits' TNT crates turn up inside the pieces. Clear a row with a crate in
  it and the crate goes off, blowing a big hole in the stack. Any crate caught in the blast goes
  off a beat later, so chains go BOOM-BOOM-BOOM, and then every loose block falls straight down
  into the holes. Falling blocks can finish new rows, which can hold more crates.

Ellie sits on one side of the next piece and the raccoon on the other, the same two as in
[Ellie's Slingshot](https://jonbcampos.github.io/angry-birds/). He's not happy about his TNT going
off. He teases when the stack gets tall, burps and toots now and then (she holds her nose), and
does a victory dance if the blocks reach the top.

**There is no game over.** When the stack reaches the top, the raccoon dances, then the whole
board goes off in one giant explosion that blows him off his perch (he comes running back). Play
carries on with an empty board, her score intact and the speed dialled back a little. Losing
turns into the biggest bang in the game.

## Controls

| Finger | Does |
| --- | --- |
| Drag sideways, anywhere | the piece follows, a column at a time |
| Tap | turn |
| Drag down slowly | drop faster |
| Flick down hard | drop all the way |

The drag is relative: her finger never has to be on the piece, so it never hides it. A gesture
belongs to one piece; once that piece lands, the rest of the drag is ignored until she lifts her
finger, so one flick never drops two pieces.

Keyboard: arrows or A/D to slide, Up/W/X to turn (Z the other way), Down/S to drop faster, Space to
drop, Esc/P to pause.

## Kid-sized tuning

All in `src/game/config.ts`:

- an **8 × 16** board, not 10 × 20, so cells are 25% bigger on a phone
- a slow start (1.1 s a row) that speeds up gently every 8 rows
- a long, forgiving landing (0.75 s, renewed by every slide or turn)
- generous wall kicks, so "turn" almost never refuses
- a ghost outline showing where the piece will land (orange where the crate will be)
- a seven-bag, so she never waits long for the long piece
- in BOOM mode a crate in about one piece in three, and never more than four pieces without one

## Art

Ellie, the raccoon, the TNT crate and the explosion are the slingshot's Gemini-painted sheets,
copied across so they're the same characters. The playroom (two moods: a calm night for PLAY, a
raccoon-raided room with fireworks for BOOM!) and the title picture are painted by Gemini from
`scripts/art-manifest.mjs`. The blocks are drawn by code, because at 25 px a bold flat colour, a
shine and a shape read better than a painting. Every piece of art is optional.

```bash
cp .env.example .env.local    # then put a Gemini API key in it (it's gitignored)
npm run art                   # generates whatever is missing; --only=id to redo one piece
npm run art:shrink            # resample to the sizes the game draws at
npm run icons                 # the home-screen icon, drawn from code
```

## Sound

Voices and music are generated by Gemini (`npm run sound`, from `scripts/sound-manifest.mjs`):
cartoon lines for Ellie and the raccoon, and Lyria music for the title, PLAY and BOOM!. Ellie's
lines are TTS for now; her real recordings replace them later (see `../ELLIE-VOICE-SCRIPT-2.md`).
Effects are synthesised in `src/core/audio.ts` and `src/core/sfx.ts`.

## Running it

```bash
npm install && npm run dev
```

Open the printed Network URL on a phone.

## How it's built

The same way as its four siblings: TypeScript, a 2D canvas, Vite, no engine and no runtime
dependencies. [DECISIONS.md](DECISIONS.md) records what was decided and why.

- **`src/game/`**: the simulation, in board cells. It never imports from `src/render/`, and it
  reports everything through an event queue that `main.ts` drains into sound, particles and the
  two characters.
- **`src/game/config.ts`**: every tuning number.
- **`src/ui/gestures.ts`**: one finger turned into slide / turn / drop.
- Events, blasts and particles live in fixed pools.

### Verifying it

```js
__game.verify()   // pieces, the bag, clearing, blasts, chains, combos, top-out, two bots, gestures, layout
__game.checkArt() // every sprite sheet has the grid the slicer expects
__game.advance(s) // run the whole loop by hand for s seconds
```
